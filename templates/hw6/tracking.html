Part 2 - Tracking between two consecutive frames

Given frames $I$ (time $t$) and $J$ (time $t+1$), the tracker finds each feature's displacement $\mathbf d$ from $G\,\boldsymbol\delta = \mathbf b_k$, iterated and run coarse-to-fine (derivation), sampling $J$ between pixels with bilinear interpolation (derivation). The predicted location $\mathbf u + \mathbf d$ is then compared with where the point actually is in frame $t+1$:

  • Template matching (NCC) - the 21 × 21 patch around the feature is searched for exhaustively in frame $t+1$ (±48 px), and the correlation peak is refined to sub-pixel precision with a parabola. This uses no gradients and no linearisation, so it's an independent measurement.
  • Your own clicks - optional. Click a point in frame $t$ and where it is in frame $t+1$ (after the first run).
  • OpenCV's calcOpticalFlowPyrLK - same method, different code. It checks that the hand-written implementation is right.

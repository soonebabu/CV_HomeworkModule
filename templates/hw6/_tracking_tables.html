Worked example - feature #{{ r.id }}

The feature that moved the most among the reliable ones, at $\mathbf u = ({{ "%.0f"|format(r.x) }},\ {{ "%.0f"|format(r.y) }})$ in frame $t$. The window is {{ 2 * w.half + 1 }} × {{ 2 * w.half + 1 }} pixels and the pyramid has {{ w.levels }} levels. Gradients $I_x, I_y$ come from the Scharr filter divided by 32, in grey levels per pixel.

1. Structure tensor at level 0

$$ G = \sum_W \begin{bmatrix} I_x^2 & I_xI_y \\ I_xI_y & I_y^2 \end{bmatrix} = \begin{bmatrix} {{ "%.1f"|format(info.G[0][0]) }} & {{ "%.1f"|format(info.G[0][1]) }} \\ {{ "%.1f"|format(info.G[1][0]) }} & {{ "%.1f"|format(info.G[1][1]) }} \end{bmatrix}, \qquad \lambda_1 = {{ "%.1f"|format(info.eig[1]) }},\ \ \lambda_2 = {{ "%.1f"|format(info.eig[0]) }} $$

Both eigenvalues are large (per window pixel $\lambda_2 / {{ (2 * w.half + 1) ** 2 }} = {{ "%.1f"|format(info.eig[0] / (2 * w.half + 1) ** 2) }}$, and the threshold is {{ lk.MIN_EIG }}). The ratio is $\lambda_1/\lambda_2 = {{ "%.2f"|format(info.eig[1] / info.eig[0]) }}$, so this is a corner and not an edge, and $G$ is safely invertible.

2. Iterations at level 0

The coarser pyramid levels hand down the initial guess $\mathbf g^0 = ({{ "%.3f"|format(info.guess[0]) }},\ {{ "%.3f"|format(info.guess[1]) }})$. Each row solves $G\boldsymbol\delta = \mathbf b_k$ with $\mathbf b_k = \sum_W \big(I(\mathbf x) - J(\mathbf x + \mathbf d_k)\big)\,[I_x, I_y]^{\mathsf T}$, where $J$ is sampled with bilinear interpolation.

$$ \mathbf u' = \mathbf u + \mathbf d = ({{ "%.0f"|format(r.x) }},\ {{ "%.0f"|format(r.y) }}) + ({{ "%.3f"|format(r.lk_dx) }},\ {{ "%.3f"|format(r.lk_dy) }}) = ({{ "%.3f"|format(r.pred_x) }},\ {{ "%.3f"|format(r.pred_y) }}) $$ $$ \text{actual (NCC peak)} = ({{ "%.3f"|format(r.act_x) }},\ {{ "%.3f"|format(r.act_y) }}), \qquad \lVert \mathbf u' - \mathbf u'_{\text{actual}} \rVert = {{ "%.3f"|format(r.err) }}\ \text{px} $$ $$ \text{OpenCV LK: } \mathbf d = ({{ "%.3f"|format(r.cv_dx) }},\ {{ "%.3f"|format(r.cv_dy) }}), \qquad \text{difference from ours} = {{ "%.4f"|format(r.err_cv) }}\ \text{px} $$

Brightness constancy check: the mean $|I(\mathbf x) - J(\mathbf x + \mathbf d)|$ over the window drops from {{ "%.2f"|format(r.res_before) }} grey levels at $\mathbf d = \mathbf 0$ to {{ "%.2f"|format(r.res_after) }} at the tracked $\mathbf d$.

4. Bilinear interpolation at the tracked position

The centre of the window lands at $(x, y) = ({{ "%.4f"|format(bl.x) }},\ {{ "%.4f"|format(bl.y) }})$ in frame $t+1$, so $x_0 = {{ bl.x0 }}$, $y_0 = {{ bl.y0 }}$, $a = {{ "%.4f"|format(bl.a) }}$, $b = {{ "%.4f"|format(bl.b) }}$. The four neighbours are:

$$ \begin{bmatrix} f_{00} & f_{10} \\ f_{01} & f_{11} \end{bmatrix} = \begin{bmatrix} {{ "%.0f"|format(bl.f00) }} & {{ "%.0f"|format(bl.f10) }} \\ {{ "%.0f"|format(bl.f01) }} & {{ "%.0f"|format(bl.f11) }} \end{bmatrix} $$ $$ f(x, y_0) = (1-a)f_{00} + a f_{10} = {{ "%.4f"|format(1 - bl.a) }}\cdot{{ "%.0f"|format(bl.f00) }} + {{ "%.4f"|format(bl.a) }}\cdot{{ "%.0f"|format(bl.f10) }} = {{ "%.4f"|format(bl.top) }} $$ $$ f(x, y_0{+}1) = (1-a)f_{01} + a f_{11} = {{ "%.4f"|format(1 - bl.a) }}\cdot{{ "%.0f"|format(bl.f01) }} + {{ "%.4f"|format(bl.a) }}\cdot{{ "%.0f"|format(bl.f11) }} = {{ "%.4f"|format(bl.bottom) }} $$ $$ f(x, y) = (1-b)\,{{ "%.4f"|format(bl.top) }} + b\,{{ "%.4f"|format(bl.bottom) }} = {{ "%.4f"|format(bl.value) }} $$

Equivalently, the weights $(1-a)(1-b), a(1-b), (1-a)b, ab$ are {{ "%.4f"|format(bl.w00) }}, {{ "%.4f"|format(bl.w10) }}, {{ "%.4f"|format(bl.w01) }}, {{ "%.4f"|format(bl.w11) }} (sum {{ "%.4f"|format(bl.w00 + bl.w10 + bl.w01 + bl.w11) }}). OpenCV's getRectSubPix at the same point gives {{ "%.4f"|format(bl.reference) }} (difference {{ "%.1e"|format((bl.value - bl.reference)|abs) }}, which is float32 rounding). For comparison, the pixel at $\mathbf u$ in frame $t$ is {{ "%.0f"|format(w.patch_value) }}: the interpolated value in frame $t+1$ is close to it, as brightness constancy says it should be.

Colab notebook: the prototype with a real video model

The web app's generator is an offline stand-in, because there's no GPU here. This notebook runs the same planner → state graph → control adapter pipeline on a free Colab GPU with a real text-to-video diffusion model (AnimateDiff, with IP-Adapter as the visual-memory adapter). It scores both arms with pretrained vision models (OWLv2 detector, DINOv2, CLIP) and optionally a Gemini Video-LLM judge.

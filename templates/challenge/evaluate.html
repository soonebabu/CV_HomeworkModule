Evaluate real generated clips

This is the feasibility test with a real video model. The prototype run exports two prompt sets for the same story:

  1. Run a prototype and download the prompt sets and plan.json.
  2. With any text-to-video model, generate one clip per scene from the baseline prompts, then again from the orchestrated prompts (with the negative prompts, and the previous clip's last frame as the image condition if the model supports image-to-video).
  3. Upload both sets below. Clips are put in scene order by file name (scene1.mp4, scene2.mp4, ...).

With a plan, cut continuity only counts cuts where the story stays in the same place, and the judge knows what each scene should show.
